# Книжный клуб

Учебный проект на Python по объектно-ориентированному программированию. В проекте четыре сущности: клуб, участник, книга и обсуждение. Данные хранятся в JSON-файлах папки `data/`.

## Данные

В примере созданы 5 участников, 7 книг и 3 обсуждения. Основной «Клуб классики» содержит два вложенных клуба: «Клуб русской классики» и «Клуб фантастики». Вложенные клубы представлены объектами `Club`; при сохранении связь записывается через `subclub_ids`.

## Структура

- `models/member.py` — участник, роли, добавление и поиск.
- `models/book.py` — книга, добавление и поиск.
- `models/discussion.py` — обсуждение книги и сообщения участников.
- `models/club.py` — клуб, его участники, книги, обсуждения и вложенные клубы.
- `storage.py` — чтение и запись JSON, восстановление связей объектов.
- `main.py` — вывод данных в терминал.
- `tests/` — автоматические тесты.

## Запуск в терминале VS Code

```bash
cd ~/Desktop/book_club
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Если виртуальное окружение уже создано и зависимости установлены, первые две команды после `cd` повторять не нужно.

Проверка тестов и стиля:

```bash
.venv/bin/python -m pytest -q
.venv/bin/python -m flake8 .
```
