# BookClub — объектная модель книжного клуба

BookClub — учебный Python-проект для практической работы №3 по ООП.
Проект сокращен до четырех основных сущностей: клуб, участник, книга и обсуждение.
Реализации через FastAPI больше нет: приложение работает как обычная Python-программа.

## Назначение

Программа демонстрирует объектную модель книжного клуба:

- участники вступают в клуб;
- книги добавляются в список клуба;
- обсуждения создаются по конкретным книгам;
- обсуждение хранит автора и сообщения;
- данные загружаются из JSON и сохраняются обратно в JSON.

## Основные классы

### `Club`

Класс описывает книжный клуб.

Атрибуты:

- `id` — идентификатор клуба;
- `name` — название клуба;
- `description` — описание клуба;
- `members` — список объектов `Member`;
- `books` — список объектов `Book`;
- `discussions` — список объектов `Discussion`.

Методы:

- `add_member()` — добавляет участника;
- `add_book()` — добавляет книгу;
- `create_discussion()` — создает обсуждение книги в клубе;
- `to_data()` — преобразует объект в данные для JSON;
- `from_data()` — создает объект из данных JSON;
- `__str__()` — возвращает строковое представление.

### `Member`

Класс описывает участника клуба.

Атрибуты:

- `id` — идентификатор участника;
- `name` — имя;
- `email` — электронная почта;
- `role` — роль в клубе.

Методы:

- `is_moderator` — свойство, показывающее наличие прав модератора;
- `to_data()` — преобразует объект в данные для JSON;
- `from_data()` — создает объект из данных JSON;
- `__str__()` — возвращает строковое представление.

### `Book`

Класс описывает книгу.

Атрибуты:

- `id` — идентификатор книги;
- `title` — название;
- `author` — автор;
- `year` — год публикации.

Методы:

- `matches_query()` — проверяет совпадение книги с поисковым запросом;
- `to_data()` — преобразует объект в данные для JSON;
- `from_data()` — создает объект из данных JSON;
- `__str__()` — возвращает строковое представление.

### `Discussion`

Класс описывает обсуждение книги.

Атрибуты:

- `id` — идентификатор обсуждения;
- `club_id` — идентификатор клуба;
- `book` — объект `Book`;
- `author` — объект `Member`;
- `topic` — тема обсуждения;
- `messages` — список сообщений.

Методы:

- `add_message()` — добавляет сообщение участника;
- `to_data()` — преобразует объект в данные для JSON;
- `from_data()` — создает объект из данных JSON;
- `__str__()` — возвращает строковое представление.

## Взаимодействие объектов

`Club` хранит коллекции объектов `Member`, `Book` и `Discussion`.
`Discussion` связан с конкретной книгой и автором, поэтому хранит объекты `Book` и `Member`, а не только их идентификаторы.
При сохранении в JSON связи преобразуются обратно в идентификаторы.

## Хранение данных

Данные хранятся в JSON-файлах в папке `data/`.
Функция `load_all()` загружает JSON и создает объекты.
Функция `save_all()` сохраняет объекты обратно в JSON.
