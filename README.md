# BookClub — сервис книжного клуба

BookClub — это Python-приложение для любителей книг, предназначенное для покупки, чтения, обсуждения и оценки литературных произведений.

## 1. Назначение проекта

BookClub — это веб-сервис для любителей книг, предназначенный для покупки книг, чтения, обсуждения и оценки литературных произведений.

Сервис позволяет пользователям находить книги, участвовать в обсуждениях, оставлять отзывы и оценки, добавлять книги в избранное и отслеживать собственный прогресс чтения.

Основная цель проекта — объединить инструменты для чтения и общения в одном сервисе и сделать организацию книжного клуба удобной и доступной в онлайн-формате.

## 2. Целевая аудитория

Целевой аудиторией проекта являются:

- люди, интересующиеся чтением и литературой;
- участники книжных клубов;
- студенты и школьники, изучающие литературу;
- пользователи, которые хотят вести статистику и отслеживать свой прогресс чтения.

## 3. Описание предметной области

Предметная область проекта — организация чтения и взаимодействия пользователей в рамках книжных клубов.

Традиционный книжный клуб предполагает выбор произведения, совместное чтение и последующее обсуждение книги участниками. При организации такого процесса возникают задачи поиска литературы, формирования состава участников, выбора книги для обсуждения, общения между участниками и контроля прогресса чтения.

BookClub переносит эти процессы в цифровую среду.

Пользователь может зарегистрироваться в системе, найти интересующую книгу. Внутри клуба участники могут выбирать книги для совместного чтения, создавать темы для обсуждения и оставлять комментарии.

Дополнительно сервис позволяет ставить книгам оценки, писать отзывы, добавлять произведения в избранное и отслеживать количество прочитанных страниц.

Таким образом, система объединяет каталог книг, социальное взаимодействие пользователей и инструменты организации книжного клуба.

## 4. Основные сущности

В проекте планируется использовать следующие основные сущности:

### Пользователь (User)

Содержит информацию о зарегистрированном пользователе:

- идентификатор;
- имя;
- электронная почта;
- пароль;
- роль;
- дата регистрации.

### Книга (Book)

Содержит информацию о литературном произведении:

- название;
- описание;
- обложка;
- год публикации;
- количество страниц;
- автор;
- жанр.

### Автор (Author)

Содержит информацию об авторе книги:

- имя;
- биографическое описание;
- фотография.

### Жанр (Genre)

Используется для классификации книг по литературным жанрам.

### Книжный клуб (Club)

Содержит информацию о созданном пользователем книжном клубе:

- название;
- описание;
- создатель;
- жанровая направленность;
- тип клуба;
- дата создания.

### Участник клуба (ClubMember)

Связывает пользователей с книжными клубами и хранит информацию о вступлении пользователя в клуб.

### Книга клуба (ClubBook)

Связывает книги с книжными клубами и позволяет определить книгу, выбранную для совместного чтения.

### Обсуждение (Discussion)

Представляет тему, созданную участником клуба для обсуждения книги.

### Комментарий (Comment)

Содержит сообщения пользователей внутри обсуждения.

### Отзыв (Review)

Позволяет пользователю поставить книге оценку и написать текстовый отзыв.

### Прогресс чтения (ReadingProgress)

Хранит информацию о процессе чтения пользователя:

- количество прочитанных страниц;
- статус книги;
- дата начала чтения;
- дата завершения.

### Избранное (Favorite)

Позволяет пользователю сохранять интересующие его книги.

## 5. Основные функции

### Работа с пользователями

- регистрация;
- авторизация;
- выход из аккаунта;
- просмотр и редактирование профиля;
- изменение пароля.

### Работа с книгами

- просмотр каталога книг;
- поиск книг;
- фильтрация по жанрам и авторам;
- сортировка книг;
- просмотр подробной информации о книге;
- добавление книги в избранное.

### Работа с книжными клубами

- просмотр доступных клубов;
- поиск клубов;
- создание собственного клуба;
- редактирование клуба;
- вступление в клуб;
- выход из клуба;
- просмотр участников клуба;
- выбор книги для совместного чтения.

### Обсуждения

- создание обсуждений;
- просмотр обсуждений;
- добавление комментариев;
- удаление собственных комментариев.

### Оценки и отзывы

- выставление оценки книге;
- написание отзыва;
- редактирование собственного отзыва;
- удаление отзыва;
- просмотр отзывов других пользователей.

### Отслеживание чтения

- добавление книги в список читаемых;
- указание количества прочитанных страниц;
- автоматический расчёт процента выполнения;
- изменение статуса книги;
- отображение завершённых книг.

### Статистика

Пользователь сможет просматривать:

- количество прочитанных книг;
- количество прочитанных страниц;
- среднюю оценку книг;
- количество книг в избранном;
- количество посещаемых клубов;
- статистику чтения за определённый период.

### Администрирование

Администратор сможет:

- добавлять и редактировать книги;
- управлять авторами и жанрами;
- удалять некорректные материалы;
- управлять пользователями;
- модерировать клубы и обсуждения.

## 6. Технологический стек

В текущей реализации проекта используется Python-стек:

- Python 3.11+;
- FastAPI — API сервиса;
- SQLAlchemy — работа с базой данных;
- PostgreSQL — основная база данных в production;
- Alembic — миграции;
- Pydantic — валидация данных;
- pytest — автоматические тесты.

## 8. Запуск проекта

### Установка зависимостей

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Запуск сервера

```bash
python main.py
```

После запуска приложение будет доступно по адресу:

- http://127.0.0.1:8000

API endpoints:

- GET / — проверка статуса сервера;
- GET /api/books — список книг;
- GET /api/clubs — список клубов;
- GET /api/users — список пользователей.
